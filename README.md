# Weather App

A responsive weather dashboard built with HTML, CSS and JavaScript. Search for a city to see live weather conditions and a short forecast.

## Features
- Search weather by city
- Current temperature, feels-like temperature, humidity and wind speed
- Current conditions and weather icons
- Five-day forecast
- Use your device location (with permission)
- Responsive layout for mobile and desktop
- Open-Meteo weather and geocoding APIs — no API key required

## Run locally
Open `index.html` in a modern browser. Internet access is required to retrieve weather data.

## APIs
- Geocoding: https://geocoding-api.open-meteo.com/
- Forecast: https://api.open-meteo.com/
